# ورشة — إدارة محل تصليح الهواتف

تطبيق عربي باتجاه RTL مبني بـ HTML وCSS وJavaScript دون اعتماد على مكتبات خارجية أو خادم.

## الأقسام
- لوحة التحكم: التصليحات النشطة، الأجهزة الجاهزة، المقبوضات وتنبيهات المخزون.
- التصليحات: الزبون والجهاز والعطل والحالة الخارجية والملحقات والتشخيص والفني والموعد والضمان والأسعار والمدفوعات. وصل قابل للطباعة ورسالة واتساب بالحالة.
- المخزون: مرجع القطعة، الأجهزة المتوافقة، الكمية، التكلفة وسعر البيع وحد إعادة الطلب ومكان التخزين.
- الزبائن والموردون: إضافة وتعديل وبحث وأزرار الاتصال وواتساب. فتح واتساب لا يرسل الرسالة تلقائيًا.
- طلبات الشراء: طلب قطعة من مورد، إلغاء الطلب أو استلامه. الاستلام يزيد الكمية مرة واحدة ويحدّث متوسط تكلفة الوحدة.
- المصروفات والإحصائيات: مصاريف التشغيل، المستحقات، قيمة المخزون، إيرادات الأجهزة المسلمة وهامش تقديري.
- الإعدادات: بيانات المحل وتصدير واستعادة JSON.

## التشغيل والنشر
انشر ملفات المستودع مباشرة باستضافة ثابتة. في GitHub Pages اختر فرع `main` والمجلد `/ (root)` من إعدادات Pages. لا توجد خطوة build.

للتشغيل محليًا استخدم خادم ملفات ثابتًا مثل `python3 -m http.server 8000`، ثم افتح `http://localhost:8000`.

## دورة العمل
1. إدخال بيانات المحل والزبائن والموردين وقطع الغيار.
2. استلام الجهاز وتحديد السعر والدفعة والموعد المتوقع.
3. تحديث التشخيص والحالة وصرف القطع من تفاصيل التصليح؛ تخصم كمياتها وتُحفظ تكلفتها وقت الصرف.
4. التواصل مع الزبون وتحديث الدفعة والحالة إلى «تم التسليم»، ثم طباعة الوصل.
5. تصدير نسخة JSON يوميًا وحفظها في مكان خاص خارج المتصفح.

سعر التصليح الإجمالي يُدخل يدويًا ويشمل أجرة العمل والقطع حسب اتفاق المحل. صرف القطعة لا يزيد السعر تلقائيًا. تعديل كمية المخزون يدويًا مخصص للجرد؛ التوريد يتم عبر طلبات الشراء. طلب شراء واحد يخص صنفًا واحدًا.

## البيانات والحدود
- البيانات تحفظ محليًا في localStorage بالمفتاح `warsha-db-v1`، ولا تُرفع إلى المستودع أو خادم.
- البيانات مرتبطة بالجهاز والمتصفح ونطاق الاستضافة. حذف بيانات المتصفح يمحوها. لا تستخدم الوضع الخاص للعمل الدائم.
- الاستعادة تتحقق من إصدار الملف والسجلات والعلاقات ثم تستبدل البيانات كاملة بعد التأكيد. لا يوجد دمج آلي.
- ملفات النسخ الاحتياطية تحتوي بيانات الزبائن وهي غير مشفرة؛ لا ترفعها إلى مستودع عام.
- لا توجد حسابات مستخدمين أو مزامنة أو حماية من مستخدم آخر لنفس جهاز ومتصفح المحل. قفل الجهاز هو مسؤولية المستخدم.
- لا تخزن كلمات مرور أجهزة الزبائن داخل الملاحظات.
- الإيراد في الإحصائيات يعتمد على الأجهزة المسلمة. المشتريات المستلمة تُعتبر مدفوعة في حساب التدفق النقدي. لا توجد إدارة ديون موردين أو محاسبة ضريبية في هذا الإصدار.

## التحقق
تم التحقق برمجيًا من صياغة JavaScript وإضافة السجلات وصرف المخزون ورفض الصرف الزائد والتحقق من المدفوعات واستعادة JSON ورفض النسخ غير الصالحة وتوليد أقسام الواجهة. لم يجر اختبار بصري فعلي في متصفح في بيئة التنفيذ؛ يُنصح بمراجعة الهاتف والحاسوب والطباعة قبل اعتماد المحل عليها يوميًا.
